# References

External resources used by the program.

## Organizations

- [Tripoli Rocketry Association](https://www.tripoli.org/) — US amateur rocketry organization, insurance, sanctioned launches
- [National Association of Rocketry](https://www.nar.org/) — US, sport rocketry with commercial motors
- [UK Rocketry Association](https://www.ukra.org.uk/) — UK equivalent

## Sites and references

- [Richard Nakka's Experimental Rocketry](https://www.nakka-rocketry.net/) — extensive KNSU/composite propellant data, motor design theory
- [BPS.space](https://www.bps.space/) — YouTube channel, practical amateur rocketry
- [Joe Barnard](https://www.youtube.com/@JoeBarnard) — BPS.space founder, propulsion focus
- [OpenRocket](https://openrocket.info/) — trajectory simulation software
- [Rocket Propulsion Analysis](https://www.rocketpropulsionanalysis.com/) — thermochemistry software

## Books

- *Rocket Propulsion Elements* by Sutton — standard reference, advanced
- *Introduction to Rocket Science and Engineering* by Taylor — accessible intro
- *Make: Rockets* by Westerfield — hobbyist-oriented

## Suppliers

- [McMaster-Carr](https://www.mcmaster.com/) — phenolic rod, hardware, materials
- [US Rockets](https://www.usrockets.com/) — commercial motor hardware, igniters
- [Apogee Components](https://www.apogeerockets.com/) — rocketry kits, electronics, recovery

## Propellant chemistry

- KNSU/KNDX: see Richard Nakka's site for detailed recipes
- APCP: see Richard Nakka's AP/Al/HTPB section

## Data sources

- [NIST WebBook](https://webbook.nist.gov/) — thermochemistry reference
- [CoolProp](http://www.coolprop.org/) — fluid properties library
